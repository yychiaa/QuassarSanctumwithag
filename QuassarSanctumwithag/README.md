# Quassar Sanctum
An interactive forensic investigation game set inside Quassar Observatory.

## Features
- 7 interactive investigation sectors
- Dynamic inspection system
- Relational Archive
- Evidence tracking
- Agent Sync
- Procedural Web Audio
- Multiple endings

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- Canvas
- Web Audio API

Current Build: v1.0 Playable Vertical Slice
